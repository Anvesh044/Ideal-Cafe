
# 🍨 Ideal Ice Cream Website

A responsive food ordering website built using **React.js** and **React-Bootstrap**, inspired by the Ideal Ice Cream brand. The site features a stylish UI with a menu, offers, user cart, dark mode, and a fun Spin the Wheel game.

## 🔧 Features

- 🧭 **Navigation Bar** with search, cart, and dark mode toggle  
- 📋 **Menu Page** displaying food items (ice creams, chaats, desserts)  
- 🎁 **Offers Page** with combos, discounts, and a spin-the-wheel game  
- 🛒 **Cart System** for managing orders  
- 🔐 **Sign In** placeholder for future user authentication
